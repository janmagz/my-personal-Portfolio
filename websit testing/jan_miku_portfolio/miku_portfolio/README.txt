JAN.EXE — Hatsune Miku-inspired portfolio starter

HOW TO RUN
1. Extract the ZIP.
2. Open index.html in Chrome, Edge, or Firefox.
3. Edit index.html in VS Code or Notepad to personalize it.

BEFORE PUBLISHING
- Replace YOUR-EMAIL@example.com
- Replace YOUR-USERNAME links
- Replace school and graduation placeholders
- Replace sample projects with real projects
- Replace the temporary hero image URL with an image you have permission to use.
  The page needs an internet connection for Google Fonts and the temporary image.

This is a static HTML/CSS website. It has no JavaScript dependencies.
